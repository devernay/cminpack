# Problems excluded from the FORTRAN-reference cross-check gate
# (examples/crosscheck.py and the CMake crosscheck_* tests).
#
# The gate uses each problem's exit parameter (info), like the original MINPACK
# test drivers: where the committed FORTRAN reference converged (info < 5) this
# build must converge too (info < 5); problems where FORTRAN itself did not
# converge (info >= 5, e.g. the maximum number of evaluations reached) are
# ignored.
#
# A few deliberately-extreme More/Garbow/Hillstrom problems sit on a knife's
# edge where the exit code itself is a compiler-dependent coin-flip: FORTRAN
# stalls with info=4 while this build hits info=5 (maxfev), or vice versa, even
# though both reach the same (near-zero) residual. Requiring a match there is
# not meaningful, so they are listed here.
#
# Format: one "nprob/dimension" per line. When the gate fails it prints the
# problem as "nprob/dim" plus both exit parameters; add that token here if the
# flip is a benign exit-code coin-flip (once listed it never fails the build).
#
# 6/4: Powell singular function (dim 4), a zero-minimum problem. The FORTRAN
#      reference exits with info=4, this build with info=5; both drive the
#      residual to ~1e-33, so the difference is just the stop code.
